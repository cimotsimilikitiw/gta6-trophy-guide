      How this order was built

      No claim without a source.

      Each stage is a reading of the official list, not a walkthrough: the chapter rows fix the story order, the counted rows fix the clean-up order, and the rows whose description names a partner or a venue go before the endgame because their moment can pass.

      Where the official description names a mission, a count, a district or a venue, that detail is quoted in the guide and marked as stated. Where it does not, the guide says so and marks the row as a reading; no location or step is invented to fill the gap.

      • Stated — the requirement is in the official description.
      • Reading — the description is a joke or a riddle; the method is this guide's inference and is labelled as such.
      • Count — the total PlayStation tracks for the trophy, from the same official list.

      Save, export, import

      Progress lives in this browser only; nothing leaves the page.

      Ticks are written to localStorage on every change. Export writes a small JSON file you can keep or move to another browser; import reads one back. The app itself fetches nothing.

      What this guide is

      An unofficial fan project.

      The trophy names, descriptions and grades are shown as the official PlayStation 5 list publishes them, including the one name printed with asterisks. Everything else is written for this guide: the route, the missable flags and the readings are original, and each row names where its facts come from.

      The look is original too: no Rockstar logo, box art or in-game screenshot is used anywhere in this app. The only images are the captures in screenshots/, which are renders of this page.
