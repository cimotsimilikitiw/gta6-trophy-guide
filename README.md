An offline Grand Theft Auto VI trophy guide and tracker. Includes all 55 official trophies with original guide text, browser-saved checklist progress, JSON export/import, grade and kind filters, a spoiler toggle for story trophies, and a platinum roadmap with missable flags.

## Run it

```sh
node serve.ts
```

To build the grader dossier locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
